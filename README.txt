[GitHub Pages 업로드]
1. 이 폴더 안의 파일(index.html, styles.css, script.js, assets 폴더)을 저장소 최상위(root)에 업로드합니다.
2. GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
3. 잠시 후 표시되는 Pages 주소로 접속합니다.
